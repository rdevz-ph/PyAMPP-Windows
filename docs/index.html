Project Overview

PyAMPP is a portable web server manager for Windows. It provides a simple desktop app to install, start, stop, and manage Apache, MySQL, PHP, and phpMyAdmin without editing configuration files by hand.

Download

Download the latest version of PyAMPP from GitHub as a standalone executable (.exe) file.

Features

Independent Processes

Apache and MySQL run as separate processes and keep working even if you close the app window.

Custom Web Root

Choose your own htdocs folder in the setup wizard or settings without moving your existing project files.

Version Presets

Choose supported versions of PHP, Apache, MySQL, and phpMyAdmin with automated setup.

Safe Updates

Update or change server versions without deleting your MySQL databases or web files.

Automatic PHP Extensions

Automatically configures php.ini with common extensions enabled, including mysqli, curl, openssl, mbstring, and zip.

Add PHP to System PATH

Add the portable PHP folder to your Windows PATH with one click to run tools like Composer from the command line.

LAN Access Switch

Allow or block other devices on your local network from opening your sites using automatic subnet detection.

Real-time Server Logs

View output and error logs from Apache and MySQL in real time from the logs tab.

Supported Versions (Presets)

PyAMPP includes tested download presets for the following components (defined in presets.json):

  • PHP: 8.5.6, 8.4.21, 8.3.31, 8.2.31, 8.1.34, 8.0.30, and 7.4.33
  • Apache: 2.4.66
  • MySQL: 8.4.4, 8.0.40, and 5.7.44
  • phpMyAdmin: 5.2.3, 5.2.2, and 5.2.1

Requirements

  • Operating System: Windows 10 or Windows 11 (64-bit).
  • Built with: Python 3 and CustomTkinter for a clean desktop interface.
  • Visual C++ Runtimes: Uses standard 64-bit Windows runtimes.

System Architecture

PyAMPP is organized into simple parts:

  • Core: Manages downloading, file extraction, settings files, and starting or stopping server processes.
  • Interface: The desktop app with tabs for the dashboard, logs, diagnostics, PHP extensions, and settings.
  • System Scripts: Simple helper scripts to configure Windows PATH and network access when requested.

Frequently Asked Questions

Why use PyAMPP instead of Docker?

Docker is powerful, but it can use a lot of memory and disk space. PyAMPP runs directly on Windows without virtualization, making it lighter and faster to start for regular PHP development.

Is PyAMPP portable?

Yes. The app runs as a single file, and all downloaded programs stay in your selected installation folder. If you move the folder to another location, update the install path in the Settings tab.

Can I use custom PHP or MySQL versions?

PyAMPP uses the versions listed in presets.json. You can also enter custom download links in the Settings tab under Custom Download URLs.

Do I need Administrator rights?

No, regular use does not need administrator rights. You only need administrator rights if you want to add PHP to your Windows system PATH.
